# 13 - Portfolio Construction

Good stock ideas do not automatically make a good portfolio. This module covers modern portfolio theory and diversification, asset allocation, rebalancing, and how much capital each position should get.

```objectives
scope: module
time: 5-6 hours
outcomes:
  - "Explain the efficient frontier and why correlation drives diversification"
  - "Calculate the expected return and volatility of a two-asset portfolio"
  - "Design an asset allocation and a rebalancing policy for a stated goal"
prerequisites:
  - "[Sharpe Ratio](../03-Risk-and-Return/Notes/02-Sharpe-Ratio.mdx)"
  - "[Asset Class Comparison](../02-Asset-Classes/Notes/06-Asset-Class-Comparison.mdx)"
```
