# 05 - The Metric Toolkit

The eight metrics institutional analysts reach for first. Each note gives the definition, the exact formula, benchmark ranges by sector, red flags, and how the metric interacts with the other seven. The final note puts them together into one dashboard.

```objectives
scope: module
time: 8-10 hours
outcomes:
  - "Calculate each of the eight metrics from a company's filings"
  - "Benchmark each metric against the right sector range rather than the whole market"
  - "Recognize the red flags that make a metric misleading"
  - "Combine the metrics into a one-page quality, value and safety dashboard"
prerequisites:
  - "[Accounting Foundations](../04-Accounting-Foundations/INDEX.mdx) - the three statements"
  - "[Compound Interest Mechanics](../01-Money-and-Compounding/Notes/01-Compound-Interest-Mechanics.mdx) - CAGR"
```

## How to Study This Module

1. Start with ROIC vs WACC - it is the reference note, and the other seven refer back to it.
2. Work through the valuation pair (P/E vs PEG, EV/EBITDA), then the cash pair (FCF Yield, Payout & Coverage).
3. Finish with How the Metrics Interact and fill in its dashboard for one company.

When you finish, take the [module quiz](/quiz/metrics) to check what stuck.
