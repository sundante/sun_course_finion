# Knowledge Check

Review for the whole course in one place. Each module's **quiz** collects every *Check Yourself* question from its pages, graded as you go, with each section linking back to the page it tests. The [quiz index](/quiz/all) lists every quiz with its question count.

```objectives
scope: module
time: As needed - about 20 minutes per module quiz
outcomes:
  - Recall and explain the key ideas of any module without the notes open
  - Find weak areas quickly by taking a module quiz, then revisit the linked pages
  - Rehearse the formulas and definitions that licensing exams and analyst interviews expect
prerequisites:
  - The module you are reviewing
```

## How to Use It

1. Take the module quiz first - it is quick and graded, and each section links back to the page it tests.
2. Revisit the pages where you missed questions, and do their exercises.
3. Explain each free-text answer out loud before revealing the model answer. If you can teach it, you know it.
4. Before a licensing exam, take every quiz in the relevant track in one sitting.
